# OurSigner

OurSigner is a Windows iOS sideloading tool.

The installed application is called **OurSign**.

## What is OurSign?

OurSign is designed to make iOS sideloading easier from Windows.

It provides a simple interface for:

- Connecting an iPhone
- Detecting an iPhone over USB
- Checking for iTunes
- Selecting an IPA file
- Managing the signing workflow
- Installing signed apps onto a connected iPhone

## Requirements

OurSigner currently requires:

- Windows 10 or Windows 11
- **64-bit (x64) Windows**
- An iPhone
- A USB cable
- iTunes installed from Apple
- An Apple Account
- A compatible IPA file
