# OurSigner

OurSigner is a Windows tool for iOS sideloading.

The installed iOS app is called **OurSign**.

## Requirements

- Windows 10/11
- **64-bit (x64) Windows**
- iPhone with a Lockscreen Code
- USB cable
- iTunes installed from Apple
- Apple Account
- IPA file

> 32-bit Windows is currently not supported.

## Installation

1. Install iTunes from Apple.
2. Download and install OurSigner.
3. Connect your iPhone with USB.
4. Unlock your iPhone.
5. Select **Trust This Computer** if prompted.
6. Open OurSigner.

## Using OurSign

1. Connect your iPhone.
2. Select an `.ipa` file.
3. Follow the signing process.
4. Install the app onto your iPhone.

## Security

OurSigner does not collect or store your Apple Account password or verification code.
